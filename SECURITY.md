# Security

SilverNote is a personal project. The hosted instance is private: it only admits its owner's account,
and no one else's data is stored in it.

If you find a vulnerability in this code, please report it privately through
[GitHub's private vulnerability reporting](https://github.com/Mando2700/silvernote/security/advisories/new)
rather than in a public issue. Please don't test against the hosted instance.
